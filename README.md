# albiononlinealimemri

sadece ve sadece agalarıma özel kodladığım o muhteşem makro

kullanım:

1. baslat.bat dosyasını çalıştır (python kurulu olmalı, kütüphaneleri otomatik kurup açar).
2. oyunda market ekranını aç.
3. programın sağındaki "kalibrasyon" butonlarına sırayla basıp 3 saniye içinde fareyi oyundaki ilgili butonların üzerine götür (bir defa yapman yeterli, koordinatları kaydeder).
4. "başlat" butonuna basınca listedeki itemlara sırayla alım emri verir.

durdurmak için klavyeden f12 tuşuna basabilirsin. kaldığı sırayı hatırlar, sonra tekrar basınca kaldığı yerden devam eder.
istediğin itemın fiyatını soldan seçip değiştirebilirsin.
tüm itemların fiyatını değiştirmek istersen "toplu fiyat" kısmına tutarı yazıp uygula diyebilirsin.
